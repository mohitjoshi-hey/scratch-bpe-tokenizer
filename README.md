# From-Scratch BPE Tokenizer

A Byte Pair Encoding (BPE) tokenizer implemented from scratch in C++.

## Current Features

- Character-level tokenization
- Adjacent token pair frequency counting
- Most frequent pair selection
- Deterministic tie-breaking
- Single BPE merge iteration
- Updated corpus generation

## Tech Stack

- C++
- STL
